# Task 2 - File Upload App Using Supabase

A cloud-based file upload application developed as part of my Cloud Computing Internship. This project demonstrates how to build and deploy a web application that allows users to authenticate, upload, view, and manage files using Supabase Storage. The application is deployed on Vercel.

## Features

* User Sign Up and Login
* Secure User Authentication using Supabase
* File Upload to Supabase Storage
* View Uploaded Files
* Delete Uploaded Files
* Responsive Web Interface
* Live Cloud Deployment

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Supabase (Authentication & Storage)
* GitHub
* Vercel
